# OA-SAR8 —— 8 位 SAR ADC（IHP SG13G2）规格书 v0.1

目标：一颗有真实功能、可流片、可被他人复用的 8 位逐次逼近 ADC，
最终集成进 `ihp-sg13g2-ams-chip-template` 骨架流片，并提交 IHP-Open-DesignLib。

## 1. 指标目标

| 参数 | 目标 | 备注 |
|---|---|---|
| 分辨率 | 8 bit | 架构可扩展至 10 bit |
| 静态精度 | INL/DNL < ±0.5 LSB（typ） | 由电容匹配保证，行为级 MC 定匹配需求 |
| ENOB | ≥ 7.5 bit（静态） | 首片目标，噪声预算见 §3 |
| 采样率 | 100 kS/s @ 1 MHz SAR 时钟 | 10 clk/次（1 采样 + 8 逼近 + 1 完成） |
| 输入范围 | 0 – VREF，单端 | VREF = VDDA = 1.5 V |
| 电源 | AVDD/DVDD 1.5 V（sg13_lv 器件） | IO 3.3 V 走模板 IO 环 |
| 功耗 | < 100 µW @ 100 kS/s | 动态比较器，无静态电流路径 |

## 2. 架构

```
 vin ──[采样开关 TG]──┬──[二进制加权 CDAC, 255+1 单位电容]── VREF/GND 开关阵列
                      │
                      └──[StrongARM 动态比较器]──► cmp
                                                    │
                    dac_code[7:0] ◄──[SAR 控制器(数字, LibreLane 宏)]◄─┘
                                        │ SPI/并口读出 + start/clk
```

- **CDAC**：电荷再分配型，单位电容 cmim 2.2×2.2µm（≈7fF），255u 二进制 + 1u 终端，总容 ≈ 1.8 pF。
  kT/C 噪声 @1.8pF = 48 µV rms ≪ LSB/√12 = 1.69 mV ✓。采样方案：track 相 top→VCM、bottom→vin；
  转换相 bottom→VREF/GND。**已在晶体管+电容级验证**（core/run_real_adc.py，3/3 码字正确）。
- **伪差分参考（核心验证中确立）**：比较器参考端不直连 VCM，而接等容复制浮空节点
  （track 采 VCM 后浮空）——单端直连时判决回踢造成 +4 LSB 系统偏差，复制节点使回踢变共模。
- **比较器**：StrongARM 锁存 + SR 锁存。**输入对定为 2µ/0.15µ**（从 8µ 缩小）：8µ 时输入对
  Cgs 过大，各相位从浮空 top plate 累积窃取电荷造成随输入变号的码偏差（低压+4/高压−4）；
  缩到 2µ 后 3/3 精确。噪声代价：σn 约 450→640µV（估），仍在 1.17mV 预算内（重新 .noise 校准待做）。
  失调靠尺寸/版图对称控制（首片不做校准）。
- **SAR 控制器**：同步 FSM（见 `rtl/sar_ctrl.sv`），比较器判决在每个时钟沿采纳。
- **失配预算**：单位电容 σ(ΔC/C) 的要求由 `model/sar_model.py` 蒙特卡洛给出。

## 3. 误差预算（LSB = 5.86 mV）

| 项 | 预算 | 依据 |
|---|---|---|
| CDAC INL（匹配） | < 0.5 LSB | MC：σ_u=1% 时良率 100% |
| 比较器输入参考噪声 | **< 0.2 LSB rms（1.17 mV）** | 动态 MC 实测：σn=0.2→ENOB 7.63，σn=0.3→7.39（不达标），预算收紧 |
| 采样 kT/C | 0.01 LSB | C=1.5 pF |
| 比较器失调 | **σos=5.67mV（60 样本 MC 实测）**，解析 5.3mV 交叉验证 | 3σ≈2.9 LSB 全局平移，不伤线性；二版可加校准 |

## 5. 时钟方案：同步基线 + 异步变体

| | 同步版 `sar_ctrl.sv` | 异步版 `sar_ctrl_async.sv` |
|---|---|---|
| 时钟需求 | 位时钟 = 10 × 采样率 | 仅采样时钟（track 下降沿启动） |
| 转换耗时 | 8 个位时钟周期 | 实测 ~16 ns（自定时环路，随比较器速度浮动） |
| 实现路径 | LibreLane 标准流程，STA 干净 | 自定时环 `fire=busy&&!valid`，需宏级手工时序，vanilla STA 不适用 |
| 验证状态 | 558/558 通过 | 558/558 通过（随机比较器延时 0.5–3ns） |
| 角色 | **流片基线**（风险控制） | 性能变体（可作第二通道同片对比） |

比较器完成检测：StrongARM 输出对 `outp XOR outn`（判决完成时恰好一高一低）。

## 6. 动态指标与噪声表征方法

- **动态测试**：相干采样正弦（4096 点，M=101 素数 bin）→ FFT → SNDR/SFDR/ENOB，
  行为级结果：理想 7.95 bit；σu=1%+σn=0.2LSB → SNDR 47.8dB / SFDR 70.1dB / **ENOB 7.64**。
  同一套 FFT 处理脚本后续直接复用于电路级 tran 和硅片测试数据。
- **比较器噪声预算 σn ≤ 0.2 LSB (1.17 mV rms)**——由 ENOB-vs-σn 扫描实测确定（0.3 LSB 时 7.39 不达标）。
- **表征方法：快速确定性流程**（决定：不用判决概率法/瞬态噪声 MC——太慢）：
  1. 闭式公式 **σn = √(4kTγ/(gm·Tint))**，其中 gm·Tint = A_int·C_PQ；
  2. A_int 与 Tint 从**一次干净瞬态**提取（秒级，无噪声无 MC），C_PQ 由版图/几何估计；
  3. 下一步用一次小信号 .noise 校准实际 γ 与 gm（仍是秒级）；
  4. VACASK PSS/HBAC 留给采样网络周期分析（PSS 为 2026.07 新增；无 pnoise）。
- **首版实测**（tt 角，尾管 3µ/0.3µ，输入对 8µ/0.15µ）：Tint=45ps，A_int=4.6，
  **σn ≈ 424 µV rms = 预算的 36%（2.8× 裕量）**；判决 0.17ns@2mV；极性 inp>inn→outp HIGH；
  0.2mV（LSB/29）正确分辨。整个表征流程耗时 <10 秒仿真。
